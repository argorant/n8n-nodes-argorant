## Description

### Who it's for
Freight forwarders, 3PLs and logistics service providers deciding which countries to prospect next.

### What it does
You list candidate countries once. The workflow counts the supply chain and logistics leaders at wholesalers, manufacturers and online retailers in each country, ranks the countries, saves the top ones as Argorant lists and writes the whole table to a Google Sheet.

### How to set up
Edit the countries, titles and the number of top markets in Settings, pick the sheet and run it.

### Requirements
n8n-nodes-argorant 0.3.0 or later, an Argorant API key, a Google Sheets credential.

### Costs
Free: counts and lists use no credits.
